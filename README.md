# 🔐 Pybersec Toolkit

A Python-based cybersecurity toolkit I'm building while learning cybersecurity, Python, and networking.

This project is part of my journey as a 2nd-year university student studying cybersecurity. The goal is to build practical security tools while developing my understanding of programming, networking, and defensive security.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/PyberSec/pybersec-toolkit.git
cd pybersec-toolkit
```

Run the port scanner:

```bash
python src/scanner.py
```

The current version scans TCP ports and reports ports that accept a connection.
